## หัวข้อที่จะเรียนในบทนี้

- CI (Continuous Integration) คืออะไร ทำไมสำคัญ
- CD (Continuous Delivery vs Continuous Deployment) ต่างกันอย่างไร
- GitHub Actions: Workflow, Job, Step, Runner
- Trigger events: `push`, `pull_request`, `workflow_dispatch`
- YAML syntax สำหรับ workflow
- Actions Marketplace: ใช้ action สำเร็จรูปของคนอื่น
- ดู workflow run ใน GitHub Actions tab
