## หัวข้อที่จะเรียนในบทนี้

- **สิ่งที่เรียนมาทั้งหมด** — วัด DORA metrics ของโปรเจกต์ตัวเองได้แล้ว
- **Kubernetes** — คืออะไร ทำอะไร ต่างจาก Docker Compose ยังไง (concept เท่านั้น)
- **DevSecOps** — Security ไม่ใช่ขั้นตอนสุดท้าย แต่อยู่ทุกที่ใน pipeline
- **GitOps** — infrastructure managed ด้วย Git (ArgoCD, Flux)
- **SRE vs DevOps** — Site Reliability Engineer คืออะไร
- **Certifications** ที่เริ่มได้เลย:
  - Docker Certified Associate
  - GitHub Actions certification (ฟรี)
  - AWS Cloud Practitioner
- **Roadmap** — ขั้นตอนต่อไปหลังจบวิชานี้

> บทนี้สำหรับ motivation — เห็นว่าวิชานี้เป็นจุดเริ่มต้น ไม่ใช่จุดสิ้นสุด
