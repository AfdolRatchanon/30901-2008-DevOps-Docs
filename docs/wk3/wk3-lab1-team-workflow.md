## สิ่งที่จะทำใน Lab นี้

- Fork โปรเจกต์ Task Tracker จาก repo ต้นแบบ
- สร้าง branch ชื่อ `feature/your-name-task`
- เพิ่ม feature เล็กๆ (เช่น เพิ่มข้อมูล task ตัวอย่าง)
- สร้าง Pull Request กลับไปที่ repo หลัก
- Review PR ของเพื่อนอย่างน้อย 1 คน — ให้ comment ที่มีประโยชน์
- แก้ตาม feedback แล้ว push อีกครั้ง

**เป้าหมาย:** เห็น PR ของตนเองถูก merge เข้า repo หลักสำเร็จ ✅
