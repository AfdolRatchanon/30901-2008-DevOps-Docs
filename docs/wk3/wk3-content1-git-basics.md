## หัวข้อที่จะเรียนในบทนี้

- Git คืออะไร — ทำไม DevOps ต้องใช้ Version Control
- Repository, Working Tree, Staging Area, Commit
- Commands พื้นฐาน: `init`, `add`, `commit`, `log`, `diff`, `status`
- Undoing: `restore`, `reset`, `revert`
- `.gitignore` — ไฟล์ไหนไม่ควร commit
- Commit message ที่ดีมีหน้าตาอย่างไร (Conventional Commits)
