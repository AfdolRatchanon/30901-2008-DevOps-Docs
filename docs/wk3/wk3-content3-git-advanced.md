## หัวข้อที่จะเรียนในบทนี้

- **git stash** — เก็บงานค้างไว้ชั่วคราวเพื่อ switch branch
  - `git stash`, `git stash pop`, `git stash list`
- **Semantic Versioning** — v1.0.0 หมายความว่าอะไร (Major.Minor.Patch)
- **Git Tags** — ทำ release ด้วย `git tag v1.0.0`
- **Conventional Commits** — format message ที่ทีมใช้ร่วมกัน
  - `feat:`, `fix:`, `docs:`, `chore:`
- **Git Hooks** — รันคำสั่งอัตโนมัติก่อน commit
- **Husky + lint-staged** — บังคับ format code ก่อน commit ได้เลย
- **Prettier** — format code อัตโนมัติ ไม่ต้องเถียงเรื่อง style

> ไม่มี `git rebase` — ซับซ้อนเกินจำเป็นสำหรับวิชานี้
