## หัวข้อที่จะเรียนในบทนี้

- Remote repositories: `clone`, `fetch`, `pull`, `push`
- Branching strategy: `branch`, `checkout`, `switch`, `merge`
- GitFlow vs Trunk-based Development
- Pull Request (PR): สร้าง → Review → Approve → Merge
- Merge Conflicts — เกิดอะไรขึ้นและแก้ยังไง
- GitHub Issues + Labels + Milestones
- Protected Branches และ Branch rules
