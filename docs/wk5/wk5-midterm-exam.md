### Checklist ก่อนส่ง

- [ ] App รันได้ local (`node src/index.js`)
- [ ] `Dockerfile` เขียนถูกต้อง — `docker build` ไม่ error
- [ ] `docker-compose.yml` รัน backend + frontend พร้อมกัน
- [ ] `docker compose up --build` แล้วเปิด `http://localhost:3000` ได้
- [ ] Git มี commit history ≥ 5 commits ที่มีความหมาย
- [ ] `README.md` อธิบายวิธีรันโปรเจกต์ครบ
