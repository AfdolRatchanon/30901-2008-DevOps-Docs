## หัวข้อที่จะเรียนในบทนี้

- Value Stream คืออะไร — เส้นทาง "idea → user ใช้งาน"
- วาด diagram ง่ายๆ แสดงทุกขั้นตอนของการ deploy 1 ครั้ง
- หา Waste: ขั้นตอนไหนที่รอนาน ซ้ำซ้อน หรือไม่สร้างคุณค่า
- Lead Time vs Process Time — ต่างกันอย่างไร
- DevOps ลด waste ได้อย่างไรในแต่ละขั้น

> ไม่มีสูตรซับซ้อน — เรียนผ่าน diagram + ตัวอย่างจริงจากบริษัทเทค
