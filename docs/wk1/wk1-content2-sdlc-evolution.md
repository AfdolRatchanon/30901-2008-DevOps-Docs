## หัวข้อที่จะเรียนในบทนี้

- Waterfall: ทำงานเสร็จทีเดียว ส่งทีเดียว — ปัญหาที่เกิดขึ้น
- Agile: ส่งทีละ sprint แต่ยังมีช่องว่างระหว่าง Dev กับ Ops
- DevOps: ทำลายกำแพงระหว่าง Dev, Ops และ QA
- เปรียบเทียบ: เวลา delivery, ความเสี่ยง, feedback loop ของแต่ละแบบ
- Timeline จริง: บริษัทใหญ่ (Netflix, Amazon) เปลี่ยนมา DevOps แล้วได้ผลอย่างไร
