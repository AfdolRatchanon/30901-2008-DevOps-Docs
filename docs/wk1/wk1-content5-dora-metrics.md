## หัวข้อที่จะเรียนในบทนี้

- DORA คืออะไร — Google วิจัยทีม DevOps 6 ปีได้ข้อสรุปอะไร
- 4 ตัวชี้วัด:
  - **Deployment Frequency** — deploy บ่อยแค่ไหน
  - **Lead Time for Changes** — code merge → production ใช้เวลากี่นาที
  - **Change Failure Rate** — deploy แล้วพังกี่ %
  - **MTTR** (Mean Time to Restore) — ระบบล่มแล้วกู้คืนได้เร็วแค่ไหน
- Elite vs Low performer — ต่างกันแค่ไหน
- นักเรียนจะวัด DORA metrics ของโปรเจกต์ตัวเองได้ใน M9
