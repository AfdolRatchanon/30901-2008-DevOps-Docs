## หัวข้อที่จะเรียนในบทนี้

- Agile คืออะไร — Sprint, Backlog, Standup, Retrospective
- DevOps เสริม Agile ตรงไหน — CI/CD ทำให้ sprint delivery เร็วขึ้นอย่างไร
- Kanban board: visualize งานที่ค้างอยู่
- GitHub Issues + Projects — Kanban board ฟรีที่ใช้ใน course นี้
- ใน 1 sprint มี CI/CD รันกี่ครั้ง — เชื่อม concept ให้เห็นภาพ

> เรียนแบบ concept + demo ใน GitHub Projects — ไม่ต้องใช้ Jira
