## หัวข้อที่จะเรียนในบทนี้

- DevOps คืออะไร และเกิดขึ้นมาแก้ปัญหาอะไร
- SDLC: Waterfall → Agile → DevOps เปลี่ยนไปอย่างไร
- Three Ways of DevOps (Flow, Feedback, Continual Learning)
- วัฒนธรรมองค์กร DevOps — Dev กับ Ops ทำงานร่วมกันอย่างไร
- Value Stream: จาก code บรรทัดแรกถึงมือ user
