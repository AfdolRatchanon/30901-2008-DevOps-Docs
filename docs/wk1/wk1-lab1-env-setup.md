## สิ่งที่จะทำใน Lab นี้

- ติดตั้ง WSL2 (Windows Subsystem for Linux) บน Windows 11
- ติดตั้ง VS Code + Extensions (Remote WSL, GitLens, Docker)
- ติดตั้ง Git และตั้งค่า user.name / user.email
- ติดตั้ง Node.js 20 LTS ผ่าน nvm
- ทดสอบ environment ว่าพร้อมใช้งาน

**เป้าหมาย:** รัน `git --version`, `node --version`, `docker --version` ใน WSL2 terminal ได้ครบทั้ง 3 คำสั่ง
