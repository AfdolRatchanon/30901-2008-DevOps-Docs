## สิ่งที่จะทำใน Lab นี้

- เขียน Shell Script สำหรับ setup โปรเจกต์อัตโนมัติ
- Script ต้องรับ argument (ชื่อโปรเจกต์) และสร้าง directory structure ให้
- เพิ่ม health-check script ที่ตรวจสอบว่า tools พร้อมใช้งานครบหรือไม่
- เรียนรู้ cron job เบื้องต้น (automate ตามเวลา)

**เป้าหมาย:** `./setup.sh my-project` แล้วได้ folder structure พร้อมใช้งานภายใน 1 คำสั่ง
