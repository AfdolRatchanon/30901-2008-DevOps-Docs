## หัวข้อที่จะเรียนในบทนี้

- Linux File System: `/`, `/home`, `/etc`, `/var`, `/tmp`
- Navigation: `pwd`, `ls`, `cd`, `tree`
- File Operations: `touch`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `less`
- Permissions: `chmod`, `chown`, `ls -la` (rwx explained)
- Process Management: `ps`, `top`, `kill`, `&`, `jobs`
- Redirection & Pipes: `>`, `>>`, `|`, `grep`, `wc`
