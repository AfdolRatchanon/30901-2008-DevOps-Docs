## หัวข้อที่จะเรียนในบทนี้

- Shebang (`#!/bin/bash`) และ execution permissions
- Variables: `NAME="value"`, `$NAME`, `${NAME}`
- User Input: `read`, `$1 $2` (positional parameters)
- Conditionals: `if`, `elif`, `else`, `[ ]`, `[[ ]]`
- Loops: `for`, `while`, `until`
- Functions: `function_name() { ... }`
- Exit codes: `$?`, `exit 0`, `exit 1`
- Real use case: script backup, cleanup, health-check
