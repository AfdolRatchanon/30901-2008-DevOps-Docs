## หัวข้อที่จะเรียนในบทนี้

- **IaaS / PaaS / SaaS** — เปรียบกับ "เช่าที่ดิน / เช่าบ้าน / เช่าโรงแรม"
- **Major providers**: AWS, GCP, Azure — แต่ละเจ้าใช้ทำอะไร
- **Render + Railway** — PaaS ที่ใช้ใน course นี้ เหมาะกับงานไหน
- **Region + Availability Zone** — ทำไม datacenter ต้องกระจายหลายที่
- **Container as a Service (CaaS)** — run Docker บน cloud แทนตั้ง server เอง
- **Free tier** — รู้จัก limitation ก่อนใช้จริง
- เปรียบ: local machine → VPS → PaaS → Serverless

> เรียนแบบ concept + diagram — ไม่ต้องสมัคร AWS
