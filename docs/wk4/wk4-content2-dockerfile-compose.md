## หัวข้อที่จะเรียนในบทนี้

- Dockerfile: `FROM`, `WORKDIR`, `COPY`, `RUN`, `EXPOSE`, `CMD`
- Build image: `docker build -t name:tag .`
- Multi-stage builds — ลดขนาด image
- `.dockerignore` — อย่า copy สิ่งที่ไม่จำเป็น
- Docker Compose: `docker-compose.yml` syntax
- Services, Networks, Volumes ใน Compose
- `docker compose up`, `down`, `logs`, `exec`
- Multi-container: backend + frontend รันพร้อมกัน
