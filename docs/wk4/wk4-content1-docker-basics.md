## หัวข้อที่จะเรียนในบทนี้

- Container vs Virtual Machine — ต่างกันอย่างไร?
- Docker Architecture: Client, Daemon, Registry
- Image: คืออะไร, สร้างมาจากไหน, layer system
- Container: รัน, หยุด, ลบ, ดู logs
- Commands: `pull`, `run`, `ps`, `stop`, `rm`, `images`, `rmi`
- Docker Hub: public registry ใช้ฟรี
- Port mapping: `-p 3000:3000`
