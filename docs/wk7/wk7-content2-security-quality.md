## หัวข้อที่จะเรียนในบทนี้

- Code Quality: ทำไม code ที่รันได้ ไม่เท่ากับ code ที่ดี
- ESLint: ตั้งค่า, rules, auto-fix
- OWASP Top 10 พื้นฐาน (เน้นที่เกี่ยวข้องกับ web API)
  - Injection (SQL, Command)
  - Broken Authentication
  - Sensitive Data Exposure
- SAST (Static Application Security Testing) เบื้องต้น
- `npm audit` — ตรวจ dependency vulnerabilities
- Secrets ไม่ควรอยู่ใน code (`.env`, GitHub Secrets)
- Shift-left Security: ตรวจความปลอดภัยตั้งแต่ต้น pipeline

**Ref Book:** Alice and Bob Learn Application Security — Chapter 1-4
