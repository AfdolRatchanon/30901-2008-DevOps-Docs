## หัวข้อที่จะเรียนในบทนี้

- Testing Pyramid: Unit → Integration (SIT) → E2E
- Unit Test, SIT, UAT คืออะไร แตกต่างกันอย่างไร
- DevOps เปลี่ยน SIT/UAT จาก manual → automated อย่างไร
- Approval Gate ก่อน deploy ขึ้น Production
- เชื่อม testing strategy เข้ากับ CI/CD pipeline
