## หัวข้อที่จะเรียนในบทนี้

- ทำไม Testing ถึงเป็นส่วนหนึ่งของ DevOps
- Unit Test vs Integration Test vs E2E Test
- Jest: `describe`, `it`, `expect`, matchers
- Test Coverage: `--coverage` flag ดู % ที่ครอบคลุม
- Test doubles: Mock, Stub, Spy
- Supertest: ทดสอบ API endpoints โดยตรง
- Test naming convention ที่ดี
- "Red-Green-Refactor" cycle (TDD เบื้องต้น)
