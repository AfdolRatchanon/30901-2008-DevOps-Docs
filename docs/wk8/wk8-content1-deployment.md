## หัวข้อที่จะเรียนในบทนี้

- Cloud Platforms สำหรับ Deploy ฟรี: Render, Railway, Fly.io
- Environment Variables บน production — `.env` ห้าม commit
- 12-Factor App Methodology (Beyond 12-Factor):
  - Factor I: Codebase — one repo, many deploys
  - Factor III: Config — store in environment
  - Factor XI: Logs — treat as event streams
- Zero-downtime deployment แนวคิดพื้นฐาน
- Rollback: ถ้า deploy แล้วพัง ทำอย่างไร
- Container Registry → Cloud Deploy workflow
