## หัวข้อที่จะเรียนในบทนี้

- **ทำไม Documentation ถึงสำคัญใน DevOps** — คนใหม่ต้อง onboard ได้ใน 1 วัน
- **README.md ที่ดี** ต้องมีอะไรบ้าง:
  - Project overview + architecture diagram
  - Prerequisites (ต้องมี tool อะไร)
  - Quick start (clone → install → run ใน 5 นาที)
  - Environment variables ที่ต้องตั้ง
  - Contributing guide
- **Runbook** — คู่มือ operation สำหรับ on-call (เชื่อมกับ incident response)
- **ADR** (Architecture Decision Record) — บันทึกว่าทำไมถึงเลือก tech นี้
- **Changelog** — บันทึกการเปลี่ยนแปลงในแต่ละ version
- Documentation อยู่ใน repo เดียวกับ code — update พร้อมกัน
