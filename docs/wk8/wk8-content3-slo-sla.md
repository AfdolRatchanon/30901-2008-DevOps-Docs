## หัวข้อที่จะเรียนในบทนี้

- **SLI** (Service Level Indicator) — ตัวเลขที่วัดจริง เช่น "latency เฉลี่ย 120ms"
- **SLO** (Service Level Objective) — เป้าหมาย เช่น "latency < 200ms 99% ของเวลา"
- **SLA** (Service Level Agreement) — สัญญากับลูกค้า เช่น "uptime 99.9%"
- **Error Budget** — ถ้า SLO คือ 99.9% มีเวลาล่มได้ 8.7 ชั่วโมง/ปี
- เปรียบ: Google Maps ล่ม 1 ชั่วโมง = error budget หมดไปเท่าไหร่
- นักเรียนคำนวณ error budget ของ Task Tracker ตัวเองได้
- ความสัมพันธ์กับ DORA Metrics

> เรียนแบบ concept + ตัวเลขจริง — ไม่มีสูตรซับซ้อน
