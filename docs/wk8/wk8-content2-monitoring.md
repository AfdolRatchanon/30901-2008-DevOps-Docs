## หัวข้อที่จะเรียนในบทนี้

- Observability: Logs, Metrics, Traces (3 pillars)
- Structured Logging: JSON logs ดีกว่า plain text ยังไง
- `console.log` vs proper logging library (pino, winston)
- Health Check endpoint: `GET /health` — pattern มาตรฐาน
- Uptime Monitoring ฟรี: UptimeRobot, BetterUptime
- Reading logs บน Render/Railway dashboard
- Alert: แจ้งเตือนเมื่อระบบมีปัญหา
- MTTR (Mean Time to Recovery) — DevOps metric สำคัญ
