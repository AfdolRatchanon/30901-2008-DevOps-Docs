1.  สาระสำคัญ (Concept) 
	ในงาน DevOps การลดขั้นตอนการทำงานแบบแมนนวล (Manual) เพื่อลดความผิดพลาดและเพิ่มความรวดเร็วเป็นสิ่งสำคัญสูงสุด การเขียน Shell Script (Bash) เป็นทักษะที่ช่วยเปลี่ยนงานที่ต้องทำซ้ำๆ หรือคำสั่งหลายๆ คำสั่งให้ทำงานต่อเนื่องเป็นระบบอัตโนมัติ (Automation) ได้ นอกจากนี้ความเข้าใจเรื่องเครือข่าย (Networking) พื้นฐาน เช่น การใช้คำสั่งตรวจสอบการเชื่อมต่ออินเทอร์เน็ต พอร์ต และการทดสอบ API เป็นสิ่งจำเป็นในการแก้ปัญหาและตรวจสอบการทำงานของระบบในสภาพแวดล้อมเครือข่าย

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจโครงสร้างและรูปแบบการเขียน Shell Script เบื้องต้น
2. สามารถเขียนสคริปต์เพื่อสร้างระบบอัตโนมัติสำหรับงานที่ทำซ้ำๆ ได้
3. เข้าใจหลักการและการใช้คำสั่ง Networking พื้นฐานใน DevOps
4. มีความตั้งใจและมีความอดทนในการแก้ปัญหาการเขียนสคริปต์ (Debugging)

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายโครงสร้าง ตัวแปร และการควบคุมทิศทาง (Loops/Conditions) ใน Shell Script ได้
2. ประยุกต์เขียน Shell Script เพื่อรวบรวมคำสั่ง Linux หลายคำสั่งเข้าด้วยกันได้
3. ใช้งานคำสั่งเครือข่าย เช่น ping, curl, และ netstat ได้อย่างถูกต้อง
4. ปฏิบัติการเขียนสคริปต์ตามโจทย์เพื่อใช้งานจริงได้สำเร็จ
5. สรุปผลลัพธ์และอธิบายโค้ดที่เขียนได้
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดี
7. ประยุกต์ใช้การเขียนสคริปต์เพื่อลดระยะเวลาการทำงาน
8. ดำเนินการและทดสอบสคริปต์อย่างระมัดระวังเพื่อป้องกันผลกระทบต่อระบบ

Shell Script และ Networking



Shell Script คือการนำคำสั่งของระบบปฏิบัติการที่พิมพ์บน Command Line มารวบรวมเขียนไว้ในไฟล์เดียว (มักจะเป็นไฟล์ .sh) และสั่งทำงานแบบมีลำดับขั้นตอน โครงสร้างของสคริปต์โดยทั่วไปจะเริ่มต้นด้วย Shebang (`#!/bin/bash`) 
สิ่งที่สามารถทำได้ใน Shell Script:
- ประกาศตัวแปร (Variables): `NAME="DevOps"` (ไม่มีเว้นวรรค) การเรียกใช้ `echo $NAME`
- เงื่อนไข (If-else): ตรวจสอบว่าไฟล์มีอยู่จริงหรือไม่
- ลูป (For/While loop): วนลูปสร้างไฟล์จำนวนมาก

Networking สำหรับ DevOps
เนื่องจากระบบ DevOps ต้องเกี่ยวข้องกับการทำงานร่วมกันของหลายเครื่องและอินเทอร์เน็ต เครื่องมือพื้นฐานที่วิศวกรทุกคนควรทราบคือ:
- `ping`: ตรวจสอบการเชื่อมต่อระดับพื้นฐานว่าเครื่องปลายทางเปิดอยู่หรือไม่
- `curl`: ใช้จำลองเป็นเบราว์เซอร์เพื่อยิง Request ทดสอบ API หรือดาวน์โหลดข้อมูลจากเว็บไซต์แบบไม่ใช้ GUI
- `netstat` หรือ `ss`: ใช้ตรวจสอบว่ามี Service อะไรเปิดพอร์ต (Port) บนเครื่องของเราอยู่บ้าง
