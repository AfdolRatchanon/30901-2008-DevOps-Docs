1.  สาระสำคัญ (Concept) 
	ซอฟต์แวร์ที่ใช้งานจริงบนระบบ Production มักไม่ได้ประกอบด้วยแอปพลิเคชันเพียงตัวเดียว แต่อาจมีส่วนประกอบอื่นๆ เช่น Backend API, Frontend Web และ Database ซึ่งการสร้างและรัน Container แต่ละตัวแยกกันด้วยมือ (Manual) จะทำให้เกิดความยุ่งยากและบริหารจัดการได้ยาก เครื่องมืออย่าง Docker Compose จึงเข้ามาช่วยจัดการให้สามารถรันหลายๆ Container พร้อมกัน และทำงานร่วมกันในวงแลนเดียวกันได้ผ่านไฟล์กำหนดค่า (docker-compose.yml) เพียงไฟล์เดียว นอกจากนี้ การทำความเข้าใจเรื่อง Docker Security ก็มีความสำคัญเพื่อป้องกันช่องโหว่ทางความปลอดภัยเมื่อนำ Image ไปรันบนระบบจริง

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจโครงสร้างการเขียนไฟล์ Dockerfile และ docker-compose.yml
2. สามารถจัดการระบบที่มีหลาย Container (Multi-container) พร้อมกันได้
3. มีความเข้าใจแนวปฏิบัติด้านความปลอดภัยเบื้องต้นของระบบ Docker
4. มีความรอบคอบและใส่ใจในรายละเอียดด้านความปลอดภัยของระบบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายโครงสร้างคำสั่งใน Dockerfile (เช่น FROM, RUN, CMD) ได้อย่างถูกต้อง
2. อธิบายความสัมพันธ์ระหว่าง Container หลายๆ ตัวภายในเครือข่ายของ Docker ได้
3. เขียนไฟล์ docker-compose.yml เพื่อตั้งค่า Multi-container เบื้องต้นได้
4. อธิบายแนวทางในการเพิ่มความปลอดภัยให้กับ Docker Container ได้
5. ปฏิบัติการจัดการและสั่งรัน Multi-container ผ่านคำสั่ง `docker-compose up` ได้สำเร็จ
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดี
7. ประยุกต์ใช้ Docker Compose เพื่อจำลองสภาพแวดล้อมเสมือนจริงของ Production
8. ปฏิบัติงานด้วยความตระหนักรู้ด้านความปลอดภัย (Security Awareness)

Dockerfile
ก่อนที่จะมี Image ให้รันเป็น Container เราต้องใช้ "Dockerfile" ในการสร้างมันขึ้นมา (Build) 
โครงสร้างสำคัญของ Dockerfile:
- `FROM`: ระบุ Base Image (เช่น FROM node:18)
- `COPY`: ก๊อปปี้ไฟล์โค้ดของเราเข้าไปใน Image
- `RUN`: รันคำสั่งขณะที่กำลังสร้าง Image (เช่น RUN npm install)
- `CMD`: คำสั่งที่จะให้รันทันทีเมื่อ Container เริ่มทำงาน

Docker Compose
เครื่องมือสำหรับนิยามและรัน Docker Application ที่มีหลาย Container (Multi-container) โดยเขียนระบุทุกอย่างไว้ในไฟล์นามสกุล YAML (docker-compose.yml) 
องค์ประกอบสำคัญ:
- `services`: เป็นตัวกำหนดว่าจะมีแอปอะไรบ้างที่รันขึ้นมา (เช่น web, db)
- `ports`: การแมปพอร์ตระหว่างเครื่องหลักกับ Container
- `volumes`: การเชื่อมโฟลเดอร์สำหรับเก็บข้อมูลถาวร
คำสั่งหลัก: `docker-compose up -d` (สั่งรันเบื้องหลัง) และ `docker-compose down` (สั่งหยุดและลบเครือข่าย)

Docker Security
เพื่อให้ปลอดภัย ห้ามให้ Container ทำงานเป็น `root` user เด็ดขาด และอย่าฝังรหัสผ่าน (Hardcode) ไว้ใน Image ให้ใช้ Environment Variables แทน
