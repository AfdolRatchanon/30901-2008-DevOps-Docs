แผนการสอนแบบฐานสมรรถนะ (Competency-based Teaching Plan)
สัปดาห์ที่ (Week)     9

รหัสวิชา (Code)     30901-2008  	วิชา (Subject)     การพัฒนาซอฟต์แวร์รูปแบบเดฟออฟส์ (DevOps Style Software Development)
หน่วยที่ (Unit)       5		ชื่อหน่วย (Name of Unit)     Midterm Project Checkpoint
หัวเรื่อง (Sub Unit)/งาน (JOB) สอบกลางภาค (Midterm Examination)

1.  สาระสำคัญ (Concept) 
	การสอบกลางภาค (Midterm Examination) เป็นการวัดและประเมินผลสัมฤทธิ์ทางการเรียนของผู้เรียนในครึ่งแรกของภาคเรียน (สัปดาห์ที่ 1-8) เพื่อตรวจสอบความรู้ความเข้าใจ ทักษะการปฏิบัติ และนำผลการประเมินไปปรับปรุงพัฒนาการจัดการเรียนการสอนในครึ่งหลังของภาคเรียน รวมถึงเป็นการทบทวนความรู้ด้าน DevOps Foundation, Linux CLI, Git & GitHub และ Docker Containerization

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. แสดงความรู้ความเข้าใจในเนื้อหาวิชาที่ได้ศึกษามา
2. มีความซื่อสัตย์สุจริตในการทำแบบทดสอบ
3. สามารถประมวลผลความรู้และแก้ไขปัญหาจากโจทย์ที่ได้รับ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
	1. ทำแบบทดสอบวัดผลสัมฤทธิ์ทางการเรียนกลางภาคได้อย่างถูกต้อง
	2. อธิบายหลักการพื้นฐานของการทำ DevOps และเทคโนโลยีที่เกี่ยวข้องได้ผ่านข้อสอบ
	3. แสดงออกถึงความซื่อสัตย์สุจริตและปฏิบัติตามกฎระเบียบการสอบอย่างเคร่งครัด
	4. มีความตรงต่อเวลาและเตรียมความพร้อมในการสอบเป็นอย่างดี

5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  การประเมินผลสัมฤทธิ์ทางการเรียน (Achievement Assessment) ดำเนินการสอบกลางภาค
	เรื่องที่/งานที่ (Sub Topic/Job)  :   Midterm Examination
	หัวข้อที่/งานที่ (Sub  Unit/Main Job)  :  สอบกลางภาค (Midterm Examination)
	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูผู้สอนชี้แจงระเบียบ กติกา และข้อปฏิบัติในการสอบกลางภาค
2. ผู้สอนจัดที่นั่งสอบและแจกข้อสอบให้กับผู้เรียน
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ผู้เรียนทำแบบทดสอบวัดผลสัมฤทธิ์ทางการเรียน (ส่วนทฤษฎีและ/หรือปฏิบัติ) ตามเวลาที่กำหนด
	ขั้นการประยุกต์เนื้อหา  (Application) 
-
	ขั้นตรวจผลสำเร็จ  (Progress)
1. รวบรวมกระดาษคำตอบและแบบทดสอบเมื่อหมดเวลาสอบ
2. ตรวจสอบความเรียบร้อยก่อนปล่อยนักศึกษาออกจากห้องสอบ

6.  การบูรณาการ (Integration)
	6.1  เนื้อหาที่บูรณาการ (Content)
		- ความซื่อสัตย์สุจริต ความมีวินัย และความตรงต่อเวลา (คุณธรรม จริยธรรม)
	6.2  ขั้นตอนการจัดทำ (Process)
		1. ผู้สอนชี้แจงระเบียบและข้อปฏิบัติในการสอบกลางภาค
		2. ผู้เรียนทำแบบทดสอบด้วยความซื่อสัตย์สุจริต
		3. ผู้สอนตรวจสอบความเรียบร้อยและรวบรวมข้อสอบ

8.  การวัด และประเมินผล (Measurement and Evaluation)

ประเมินผลจากคะแนนสอบกลางภาค
