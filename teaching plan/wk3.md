หัวเรื่อง (Sub Unit)/งาน (JOB) การใช้งานคำสั่ง Linux ขั้นพื้นฐาน (Linux CLI) และการจัดการข้อความ (Text Processing)

1.  สาระสำคัญ (Concept) 
	Linux เป็นระบบปฏิบัติการพื้นฐานที่สำคัญที่สุดในโลกของ DevOps การทำงานส่วนใหญ่บนเซิร์ฟเวอร์หรือบนระบบ Cloud จะกระทำผ่านทาง Command Line Interface (CLI) ทั้งสิ้น การมีความรู้ความเข้าใจในการนำทาง (Navigation) การจัดการไฟล์และไดเรกทอรี การตั้งค่าสิทธิ์ (Permissions) รวมถึงการใช้เครื่องมือ Text Processing (เช่น grep, awk, sed) จะช่วยให้วิศวกร DevOps สามารถจัดการเซิร์ฟเวอร์ ค้นหาข้อมูล และวิเคราะห์ล็อกไฟล์ (Log Analysis) เพื่อแก้ปัญหาระบบได้อย่างรวดเร็วและมีประสิทธิภาพ

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจโครงสร้างไฟล์และคำสั่งพื้นฐานในระบบปฏิบัติการ Linux
2. สามารถใช้คำสั่งเกี่ยวกับ Text Processing ในการจัดการข้อความได้
3. มีทักษะในการวิเคราะห์ Log (Log Analysis) เบื้องต้น
4. มีความรอบคอบและระมัดระวังในการใช้คำสั่งในระบบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. ใช้งานคำสั่ง Linux CLI เพื่อจัดการไฟล์และไดเรกทอรีได้อย่างถูกต้อง
2. อธิบายและกำหนดสิทธิ์ของไฟล์ (File Permissions) ใน Linux ได้
3. ใช้งานเครื่องมือ Text Processing เช่น grep, awk และ sed ได้
4. วิเคราะห์และค้นหาความผิดปกติจาก Log File ได้
5. สรุปผลการปฏิบัติการและการใช้คำสั่งลงในสมุดจด
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดี
7. ประยุกต์ใช้คำสั่งต่างๆ ในการค้นหาข้อมูลเพื่อแก้ปัญหาได้อย่างรวดเร็ว
8. ประยุกต์ใช้เครื่องมือในการทำงานอย่างมีวิจารณญาณและระมัดระวัง

Linux Command Line Interface (CLI) คืออินเทอร์เฟซที่ให้ผู้ใช้สั่งงานคอมพิวเตอร์ผ่านการพิมพ์คำความ (Text) แทนการใช้เมาส์คลิก ซึ่งเป็นสิ่งที่จำเป็นอย่างมากสำหรับเซิร์ฟเวอร์ที่มักจะไม่มี GUI เพื่อประหยัดทรัพยากร
คำสั่งพื้นฐานประกอบด้วย:
- นำทาง: `pwd` (ดูตำแหน่งปัจจุบัน), `cd` (เปลี่ยนไดเรกทอรี), `ls` (แสดงรายการไฟล์)
- จัดการไฟล์: `touch` (สร้างไฟล์), `mkdir` (สร้างโฟลเดอร์), `rm` (ลบไฟล์), `cp` (คัดลอก), `mv` (ย้าย/เปลี่ยนชื่อ)
- จัดการสิทธิ์: `chmod` (เปลี่ยนสิทธิ์การเข้าถึง Read/Write/Execute), `chown` (เปลี่ยนเจ้าของไฟล์)

Text Processing 
ใน DevOps การวิเคราะห์ Log เป็นสิ่งที่เจอบ่อยมาก เครื่องมือที่ใช้ในการจัดการข้อความได้แก่:
- `cat`, `less`, `tail`, `head`: ใช้เปิดอ่านไฟล์
- `grep`: ค้นหาข้อความหรือบรรทัดที่มีคำที่ต้องการ (เช่น ค้นหาคำว่า ERROR ในไฟล์ Log)
- `awk` และ `sed`: เครื่องมือจัดการข้อความขั้นสูง สามารถตัดแบ่งคอลัมน์ หรือค้นหาและแทนที่คำสั่งตาม Pattern ได้
