1.  สาระสำคัญ (Concept) 
	การพัฒนาโปรแกรมในยุคปัจจุบันมักประสบปัญหาการนำโค้ดไปรันบนเซิร์ฟเวอร์หรือบนเครื่องอื่นแล้วทำงานไม่ได้ (Works on my machine) เทคโนโลยี Container อย่าง Docker จึงเข้ามาแก้ปัญหานี้โดยการจำลองและแพ็กเกจสภาพแวดล้อมทั้งหมดที่โปรแกรมต้องใช้ใส่ลงใน "กล่อง" (Container) ทำให้สามารถนำไปรันบนเครื่องใดหรือบนระบบ Cloud ใดก็ได้โดยยังคงการทำงานที่เหมือนเดิมทุกประการ ในสัปดาห์นี้จะมุ่งเน้นที่ความเข้าใจความแตกต่างระหว่าง VM กับ Container, โครงสร้างของ Docker (Image, Container, Registry) รวมถึงภาพรวมของระบบ Cloud Computing เบื้องต้น

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจพื้นฐานเกี่ยวกับ Cloud Computing และเทคโนโลยี Container
2. สามารถแยกแยะความแตกต่างระหว่าง Virtual Machine และ Container ได้
3. มีทักษะในการติดตั้งและใช้คำสั่งพื้นฐานของ Docker
4. มีความตั้งใจและรับผิดชอบในการลงมือปฏิบัติงานทางด้าน Containerization

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายองค์ประกอบของ Docker (Image, Container, Registry) ได้อย่างถูกต้อง
2. เปรียบเทียบความแตกต่างระหว่าง Virtual Machine (VM) และ Container ได้
3. ใช้งานคำสั่งพื้นฐานของ Docker (docker run, ps, stop, rm, images) ได้
4. ปฏิบัติการดึง Image และรัน Container เบื้องต้น (Containerize) ได้สำเร็จ
5. สรุปผลลัพธ์การเรียนรู้และการใช้คำสั่งจัดการ Container ลงในสมุดจด
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดี
7. ประยุกต์ใช้เทคโนโลยี Container เพื่อแก้ปัญหาความเข้ากันไม่ได้ของสภาพแวดล้อมโปรแกรม
8. ปฏิบัติการด้วยความรอบคอบเพื่อไม่ให้กระทบกับระบบไฟล์ภายในเครื่องหลัก

Cloud Fundamentals: Cloud Computing คือการให้บริการทรัพยากรคอมพิวเตอร์ผ่านอินเทอร์เน็ต เช่น เซิร์ฟเวอร์ ฐานข้อมูล และซอฟต์แวร์ โดยผู้ใช้ไม่ต้องลงทุนซื้อฮาร์ดแวร์เอง มีรูปแบบบริการ 3 ระดับ คือ IaaS (Infrastructure as a Service), PaaS (Platform as a Service) และ SaaS (Software as a Service)

Docker Basics: 
Docker เป็นแพลตฟอร์มที่ใช้จัดการ Container ซึ่งเบากว่า Virtual Machine (VM) เพราะ VM ต้องมีระบบปฏิบัติการ (Guest OS) จำลองตัวเองอยู่ข้างในทุกตัว แต่ Container จะแชร์การทำงานร่วมกับ OS ของเครื่องหลัก ทำให้ใช้ทรัพยากรน้อยกว่า บูตเร็วกว่า

องค์ประกอบของ Docker:
1. Docker Image: เปรียบเสมือนแม่พิมพ์ที่เอาไว้สร้าง Container เป็นไฟล์อ่านอย่างเดียว (Read-only) ที่บรรจุโค้ดและสภาพแวดล้อมทุกอย่างเอาไว้
2. Docker Container: คือสภาวะการรัน (Runtime) ของ Image เป็นที่ที่โปรแกรมของเราทำงานอยู่จริงๆ
3. Docker Registry (Docker Hub): พื้นที่เก็บรวบรวม Image เพื่อให้คนสามารถดาวน์โหลดไปใช้งานได้ (คล้ายๆ App Store)

คำสั่งพื้นฐาน:
- `docker run <image>`: สั่งรัน Image ให้กลายเป็น Container
- `docker ps`: ดูรายการ Container ที่กำลังทำงานอยู่
- `docker stop <container_id>`: หยุดการทำงานของ Container

2. คุณภาพผลงาน

    2.1 วัดไม่ได้

         - ทักษะการอ่าน Logs เมื่อโปรแกรมภายใน Container มีปัญหา

         - ความสามารถในการประยุกต์และตั้งค่า Port ตามโจทย์
