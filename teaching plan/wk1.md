หัวเรื่อง (Sub Unit)/งาน (JOB) ความรู้เบื้องต้นเกี่ยวกับ DevOps, การวิวัฒนาการของ SDLC และ Value Stream

1.  สาระสำคัญ (Concept) 
	การพัฒนาซอฟต์แวร์ตามกระบวนการเดฟออฟส์ (DevOps) เป็นการผสมผสานระหว่างฝั่ง Development (Dev) และ Operations (Ops) เพื่อลดช่องว่างในการทำงาน โดยเน้นไปที่การทำงานร่วมกัน การสื่อสาร และการใช้เครื่องมืออัตโนมัติ ซึ่งสัปดาห์นี้จะมุ่งเน้นไปที่การทำความเข้าใจความหมายของ DevOps, การเปลี่ยนแปลงและวิวัฒนาการของ Software Development Life Cycle (SDLC) ตั้งแต่ยุค Traditional มาจนถึง DevOps รวมถึงแนวคิดเรื่อง Value Stream และวัฒนธรรม Three Ways ของ DevOps ที่ช่วยให้เห็นภาพรวมของการส่งมอบคุณค่าทางซอฟต์แวร์ให้กับผู้ใช้งาน

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจในพื้นฐานทั่วไปและวัฒนธรรมของกระบวนการ DevOps
2. สามารถอธิบายการวิวัฒนาการของ SDLC ได้
3. มีความเข้าใจเรื่อง Value Stream และ Three Ways of DevOps
4. มีความตั้งใจ และรับผิดชอบในการศึกษาค้นคว้า

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายความหมายและกระบวนการของ DevOps ได้อย่างถูกต้อง
2. เปรียบเทียบการทำงานแบบ Traditional และ DevOps ได้
3. อธิบายหลักการของ Value Stream ได้
4. สรุปเนื้อหาและแนวคิดของ DevOps ได้
5. ประเมินความเข้าใจเบื้องต้นของการพัฒนาซอฟต์แวร์ได้
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
7. ประยุกต์แนวทางการทำงานเป็นทีมและการสื่อสารตามหลักการ DevOps
8. ประยุกต์ใช้เป็นแนวทางในการทำงานและเรียนรู้อย่างเป็นระบบ

DevOps เป็นการผสมผสานระหว่างคำว่า Development (การพัฒนา) และ Operations (การดำเนินงาน) เป็นวัฒนธรรม แนวปฏิบัติ และเครื่องมือที่นำมาใช้เพื่อเพิ่มขีดความสามารถขององค์กรในการส่งมอบแอปพลิเคชันและบริการด้วยความเร็วสูง พัฒนาและปรับปรุงผลิตภัณฑ์ได้เร็วกว่าองค์กรที่ใช้กระบวนการพัฒนาซอฟต์แวร์และการจัดการโครงสร้างพื้นฐานแบบดั้งเดิม 

SDLC (Software Development Life Cycle) เป็นวงจรการพัฒนาซอฟต์แวร์ ซึ่งมีการวิวัฒนาการมาหลายยุค ตั้งแต่:
1. Waterfall Model: เป็นการทำงานแบบเป็นลำดับขั้น ต้องรอให้ขั้นตอนหนึ่งเสร็จก่อนจึงจะทำขั้นตอนต่อไปได้ ทำให้ล่าช้า
2. Agile: เน้นการทำงานแบบวนรอบ (Iterative) และส่งมอบงานทีละส่วน (Incremental) เพื่อให้ปรับตัวเข้ากับการเปลี่ยนแปลงได้เร็วขึ้น
3. DevOps: ต่อยอดจาก Agile โดยนำทีม Development และ Operations มารวมกัน พร้อมกับนำระบบอัตโนมัติ (Automation) มาใช้ตลอดวงจรชีวิตซอฟต์แวร์ (CI/CD)

Value Stream คือกระบวนการทั้งหมดที่องค์กรใช้ในการส่งมอบคุณค่าให้กับลูกค้า ตั้งแต่เริ่มต้นคิดไอเดียไปจนถึงการส่งมอบซอฟต์แวร์ถึงมือผู้ใช้ การทำความเข้าใจ Value Stream จะช่วยให้เรามองเห็นคอขวด (Bottleneck) และหาทางกำจัดเพื่อเพิ่มความเร็วในการทำงาน
